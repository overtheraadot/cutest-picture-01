A chubby baby axolotl floating in soft pastel water — huge sparkling eyes,
rosy blush cheeks, a tiny smile, a little pink bow on her head, and a tiny
orange fish friend swimming beside her. Drawn entirely in code: Python 3
standard library only, no image files, no network.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out python3 main.py
```

This writes `out/entry.png` (1024×1024, deterministic — every run produces
byte-identical output).
